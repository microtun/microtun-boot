# CYW43439 firmware (Pico 2 W)

Used only with the `pico2-w` feature, to start the radio that drives the
Pico 2 W's on-board LED.

Copied unchanged from [embassy-rs/embassy](https://github.com/embassy-rs/embassy/tree/cyw43-pio-v0.10.0/cyw43-firmware)
at tag `cyw43-pio-v0.10.0`, which in turn sources them from
[georgerobotics/cyw43-driver](https://github.com/georgerobotics/cyw43-driver/tree/main/firmware).

| File | Purpose |
|---|---|
| `43439A0.bin` | Wi-Fi firmware |
| `43439A0_clm.bin` | Country locale matrix |
| `nvram_rp2040.bin` | Board NVRAM (same module on Pico W and Pico 2 W) |
